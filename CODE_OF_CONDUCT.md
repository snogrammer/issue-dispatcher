# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussion about the work. Harassment and personal attacks aren't tolerated.

Report concerns privately to the maintainers using the contact listed for the
repository. Maintainers will review reports promptly and confidentially.
